# parting sky

Departure under open skies

An original solo piano composition that drifts between quiet farewell and open space.

Soft, contemplative, and spacious - written for those moments when something ends and the sky feels endlessly wide.

## Stack

- [Next.js 16](https://nextjs.org) (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- GSAP

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
